Overview
--------
AudioTester is a freeware tool to test for errors in MP3, Ogg Vorbis,
FLAC & WavPack files. To use, simply drop files/folders onto the main
program window. AudioTester takes advantage of multiple CPUs.


Command Line Options
--------------------
AudioTester <filename>
- tests the specified file/folder
